# Radar Odometry 데이터 수집 실험

## 1. 목적

자동 radar odometry는 연속 radar frame 사이의 고정 물체 변화를 이용해 센서의 이동과
회전을 추정한다. 실시간 알고리즘부터 작성하면 센서 입력, 알고리즘, 시간 동기화 문제가
섞이므로 먼저 rosbag을 수집한다. 같은 bag을 반복 재생하면 매번 완전히 같은 입력으로
파라미터와 알고리즘을 비교하고 실패를 재현할 수 있다.

## 2. 설치와 환경 고정

- 레이더 높이와 yaw/pitch/roll이 움직이지 않도록 단단한 손잡이 또는 지그에 고정한다.
- 바닥 테이프로 시작점, 1 m 끝점, 90도 회전 기준선, L자 꼭짓점을 표시한다.
- 벽, 기둥, 큰 상자처럼 움직이지 않고 여러 각도에서 보이는 특징물을 시야에 둔다.
- 사람과 이동 물체는 실제 센서 이동과 구분하기 어려우므로 실험 구역 통행을 막는다.
- 빠른 이동은 약 4.7 Hz frame 사이 변화를 크게 하고 motion blur/매칭 실패를 유발한다.
  일정하고 느린 속도로 이동하며 시작과 끝에서 2~3초 정지한다.
- 높이, 실제 이동량, 회전각, 환경은 측정한 값만 YAML에 기록한다. 추측값은 쓰지 않는다.

## 3. 기록과 검사

레이더 launch가 정상 동작하는 별도 터미널 환경에서 recorder를 실행한다. recorder는
`/radar/points`, `/radar/scan`의 존재·실제 수신·현재 Hz를 검사한 뒤에만 기록한다.

```bash
rosrun iwrl6432_ros radar_bag_recorder.py static_15s
rosrun iwrl6432_ros inspect_radar_bag.py ~/iwrl6432_mapping_ws/bags/<파일>.bag
```

기본 저장 위치는 `~/iwrl6432_mapping_ws/bags`이다. bag은 크고 실험 원본 데이터이므로
Git에 포함하지 않는다. 종료는 Ctrl+C를 사용한다. recorder는 먼저 SIGINT, 필요할 때만
SIGTERM을 보내고 `.active` 잔존 여부를 검사한 뒤 같은 이름의 YAML을 생성한다.

Inspector 판정 기준은 다음과 같다.

- FAIL: 필수 radar 토픽 누락, 전체 길이 3초 미만, 메시지 0개, PointCloud2의 80% 초과가 빈 frame
- WARNING: `/radar/points` 또는 `/radar/scan`의 1초 초과 공백, finite range가 0인
  scan 3회 이상 연속, 평균 point width 5 미만
- PASS: 필수 데이터가 있고 위 FAIL/WARNING 조건이 없음

## 4. 실험 1: `static_15s`

- 목적: 센서가 정지했을 때 노이즈, point 지속성, scan 공백을 측정한다.
- 시작 자세: 표시한 시작점에서 정면 기준선과 yaw를 맞추고 완전히 고정한다.
- 이동 방법: 15초 이상 움직이지 않는다.
- 실제 거리 측정: translation 0 m, rotation 0도로 기록하되 실제로 고정됐는지 확인한다.
- 기록 시간: 앞뒤 여유를 포함해 15~20초.
- 성공 기준: 필수 토픽 연속 수신, inspector PASS 또는 원인이 설명 가능한 WARNING.
- 실패 사례: 손떨림, 사람이 통과함, point 대부분이 비어 있음, 15초 전에 종료함.

## 5. 실험 2: `straight_1m`

- 목적: 순수 직선 이동의 frame 간 변위와 누적 오차를 측정한다.
- 시작 자세: 시작 테이프에서 센서를 정면으로 유지하고 2~3초 정지한다.
- 이동 방법: yaw와 높이를 고정해 1 m 테이프 선을 따라 천천히 이동하고 끝에서 정지한다.
- 실제 거리 측정: 줄자로 센서 기준점의 시작·끝 위치를 재어 X/Y 이동량을 YAML에 기록한다.
- 기록 시간: 시작/종료 정지 구간을 포함해 약 15~25초.
- 성공 기준: 1 m 전체에서 point와 scan이 연속적이고 고정 특징물이 유지된다.
- 실패 사례: 좌우 흔들림, 레이더 회전, 급가속, 끝점 초과, 동적 물체가 시야를 가림.

## 6. 실험 3: `rotate_90deg`

- 목적: 제자리 yaw 회전 추정과 병진/회전 분리 성능을 측정한다.
- 시작 자세: 센서 기준점을 회전 중심 표시에 두고 0도 기준선에 맞춘다.
- 이동 방법: 중심 위치와 높이를 유지하며 90도 테이프 기준선까지 천천히 회전한다.
- 실제 거리 측정: 각도기 또는 직각 기준선으로 시작·끝 yaw 차이를 측정한다.
- 기록 시간: 양 끝 정지 구간을 포함해 약 15~20초.
- 성공 기준: 약 90도 회전 동안 필수 토픽이 연속적이며 주변 고정 특징물이 충분하다.
- 실패 사례: 회전 중 센서가 원을 그리며 이동, pitch/roll 변화, 너무 빠른 회전.

## 7. 실험 4: `l_shape`

- 목적: 직선 이동과 90도 회전이 결합된 경로에서 누적 pose를 검증한다.
- 시작 자세: L자 첫 선의 시작점과 정면 기준에 맞춰 2~3초 정지한다.
- 이동 방법: 첫 직선, 꼭짓점 정지, 90도 회전, 두 번째 직선을 순서대로 천천히 수행한다.
- 실제 거리 측정: 두 직선 길이와 회전각을 줄자·테이프·각도 기준선으로 각각 측정한다.
- 기록 시간: 전체 경로와 정지 구간을 포함해 약 25~40초.
- 성공 기준: 모든 구간에 연속 데이터가 있고 각 구간의 실측값이 YAML에 남는다.
- 실패 사례: 꼭짓점을 둥글게 회전, 순서를 기록하지 않음, 특징물이 부족한 빈 공간.

## 8. 실험 순서

항상 `static_15s`부터 검사한다. 성공한 bag과 YAML은 보존하고 inspector 결과를 실험
노트에 남긴다. 그다음 `straight_1m`, `rotate_90deg`, `l_shape` 순으로 진행한다.
